# ARP Spoofing e SQL Injection: Attacco e Difesa

Progetto universitario per l'esame di fondamenti di cybersecurity realizzato in un ambiente virtualizzato VMware, con l'obiettivo di simulare attacchi informatici e verificarne le contromisure.

## Tecnologie utilizzate

- **Virtualizzazione:** VMware Workstation Pro
- **Sistemi operativi:** Kali Linux, Ubuntu Server
- **Analisi di rete:** Wireshark
- **Attacchi:** ARP Spoofing, SQL Injection
- **Applicazione web:** Apache, PHP, MySQL
- **Contromisure:** ARPwatch, ARP statico, Prepared Statements, ModSecurity WAF, hashing bcrypt

## Attività svolte

- Simulazione di ARP Spoofing e analisi del traffico di rete.
- Sfruttamento di una vulnerabilità SQL Injection in un'applicazione web di laboratorio.
- Implementazione e verifica di contromisure a livello di rete e applicativo.
- Analisi dei risultati e valutazione dell'efficacia delle difese.
